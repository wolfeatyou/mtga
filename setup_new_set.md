# ЗАВЕДЕНИЕ НОВОГО СЕТА

> Разовая процедура. Во время драфта не нужна.

## Adding a new set
1. `<set>_set.json` — Scryfall cards (`https://api.scryfall.com/cards/search?q=set:<code>&unique=cards`, send a User-Agent header; листай `next_page`).
2. **`python3 build_arena_ids.py <set>` — ОБЯЗАТЕЛЬНО, иначе сет недрафтуем.** `draft_live.py`
   резолвит пак **только по `arena_id`**, а Scryfall и MTGJSON присваивают их с задержкой в
   несколько дней после релиза (на HOB в день выхода: **0 из 193** в обоих источниках). Скрипт
   берёт id из локальной базы клиента Arena (`Raw_CardDatabase_*.mtga`), где они уже есть все.
   Проверка корректности джойна — сверка P/T со Scryfall (`--dry-run` покажет непойманные имена).
3. `17l_<set>_premierdraft.json` — рейтинги 17Lands: **`python3 fetch_17l.py <set>`**. Скрипт
   отказывается записывать непрогретые данные и печатает, сколько карт перешагнуло порог
   `game_count>200`. Сет живёт без этого файла — просто без GIH/IWD/ALSA.
4. **Одна строка в `sets_registry.py`** — `"<set>": "17l_<set>_premierdraft.json"` в начало
   `RATING_FILE` (порядок = приоритет автодетекта, текущий сет первым). Всё, больше нигде
   править не надо: девять скриптов берут список оттуда.
   > До 16.08.2026 whitelist был скопирован в 9 файлов, и здесь стояла инструкция «поправь
   > в девяти местах». Инструкция вместо починки — тот же приём, что лечить сортировку прозой;
   > класс ошибок «завёл сет, забыл файл» она не убирала. `quickdraft.py`/`quickdraft_watch.py`
   > берут код из argv свободно и правок не требуют.
5. **Файлы знаний (иначе драфтишь вслепую по одному GIH):** заведи `<set>_knowledge.md` (драфт-мета) и `<set>_insights.md` (инсайты из игр) — оба читаются перед КАЖДЫМ драфтом (§ Накопленные знания). Плюс справка: `<set>_cheat.md` (или строки в `draft_cheat.md`) и `<set>_tier.md`. Первый драфт сета — стартуй с пустых knowledge/insights и наполняй после каждого драфта/разбора.
